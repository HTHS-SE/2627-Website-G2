PID

PID controllers are used in almost every robotic system. They are used to control the behavior of the system and allow for precise movements from the initial heading to the desired course. PID stands for Proportional, Integral, and Derivative. PID's measure differences between the desired and actual values of a system to find an error value. It then combines the three corrective actions to produce a fix. It applies this fix and starts the process again. The proportional fix multiplies the error by a constant to determine the corrective action. The integral fix accumulates past errors to eliminate steady-state error The derivative fix predicts future errors to improve system stability.



Path following

Path following software's work by taking a predefined path and adjusting the robot's movements to stay on the course. To stay on course the softwares monitors the robot's position and makes adjustments using PIDs. The software controls the steering, speed, direction and other factors to perform percise movements. The software loads the map (path) as a set of ponits and uses them to guide the robot along the desired trajectory.
